# Изменения, внесённые при переводе

Русское издание является **переводом** оригинального проекта
[QMHTMY/RustBook](https://github.com/QMHTMY/RustBook). Ниже перечислены все
осознанные отличия от английского издания.

---

## 1. Перевод текста

Переведены полностью, без сокращений:

* заголовки глав, разделов и подразделов (номера разделов сохранены);
* весь авторский текст — 812 абзацев;
* маркированные списки (57 пунктов);
* подписи к рисункам и таблицам;
* содержимое таблиц (21 таблица) — за исключением имён API, литеральных
  значений и обозначений сложности;
* названия алгоритмов и структур данных — по единому глоссарию
  (`ru/glossary.md`);
* раздел «Библиография» — заголовок переведён, библиографические записи
  оставлены в исходном виде (авторы, названия, издательства, годы, URL).

Идентификаторы Rust (`Vec`, `push`, `usize`, `Self`, `Cargo`, `rustc`, имена
функций, полей и переменных) **не переводятся и не переименовываются**.

## 2. Код

Все **467 блоков кода** воспроизведены **побайтово идентично** английскому
изданию. Это осознанное решение:

* код в книге иллюстрирует алгоритмы, а не служит источником для
  копирования; побайтовое совпадение позволяет сверять русское издание с
  оригиналом машинно;
* в оригинальных листингах есть дефекты (см. `../TRANSLATION_PROGRESS.md`,
  раздел 4), и любое вмешательство в код увеличило бы риск незаметной ошибки.

**Комментарии внутри кода оставлены на английском языке.** Перевод
комментариев допускался, но не выполнялся, чтобы сохранить побайтовое
совпадение блоков и возможность автоматической проверки.

Каталог `ru/code/` — копия `original/publication/code/` оригинала без
изменений.

## 3. Иллюстрации

* Все 69 иллюстраций извлечены из оригинального PDF: растровые — в исходном
  разрешении, векторные — отрисованы в 300 dpi. Оригиналы сохранены в
  `ru/images/`.
* Для 17 рисунков созданы русские версии в `ru/images/ru/`: **61 надпись**
  внутри рисунков переведена (например, «Computer» → «Компьютер»,
  «Integrated Circuit» → «Интегральная схема», «Heat the pan» → «Нагреть
  сковороду»). Векторная графика оригинала при этом не изменяется.
* В книге используются русские версии; оригиналы остаются в репозитории.
* Числовые подписи, имена вершин, имена людей и компаний, названия API и
  названия учебных заведений внутри рисунков **не переводились**.

## 4. Восстановление дефектов вёрстки

Оригинальный PDF — результат автоматической вёрстки, из-за чего некоторые
абзацы разорваны переносом страницы, а формулы разобраны на отдельные
фрагменты. При переводе:

* разорванные посреди предложения абзацы **восстановлены в цельные** там,
  где это не меняло структуру главы (§2.4, §2.6, §4.3.3, §4.3.4, §9.8.1,
  §10.8.1);
* формулы (3.1), (5.1)–(5.4), (6.1), (7.1), (7.2), (10.1)–(10.5)
  **пересобраны** в читаемый вид с нормальными степенями (`O(n^2)`, `n^3`,
  `2^n`, `O(n log n)`) и сохранёнными знаками `∑`, `⊕`, `−`, `≠`;
* курсивные обозначения вроде `O(n2)` приведены к виду `O(n²)`;
* кавычки оригинала (`”…”` с двумя закрывающими) заменены на русские
  «ёлочки».

Это единственные случаи, где структура текста отличается от извлечённого
оригинала; все они перечислены в отчёте о качестве.

## 5. Технические средства

Оригинальный проект не содержит исходников книги в Markdown, поэтому
русское издание собрано собственным конвейером (`tools/`):

| Инструмент | Назначение |
|---|---|
| `extract_book.py` | структурный разбор PDF оригинала |
| `extract_figures.py` | извлечение иллюстраций |
| `verify_chars.py` | посимвольная проверка полноты извлечения |
| `make_markdown.py` | сборка Markdown-исходника из структуры |
| `check_translation.py` | проверка структуры и побайтового совпадения кода |
| `find_gaps.py`, `apply_gaps.py` | поиск и заполнение непереведённых абзацев |
| `rebuild_from_source.py` | восстановление границ блоков кода по оригиналу |
| `build_book.py` | сборка HTML-книги и PDF |
| `pdf_post.py` | доработка PDF и статистика |
| `final_check.py` | итоговая сверка издания с оригиналом |

## 6. Что не изменялось

* Авторство, название и сведения об издании оригинала.
* Лицензия — Apache License 2.0 (см. `../LICENSE` и `../NOTICE.md`).
* Исходный код книги (`ru/code/`).
* Структура разделов, нумерация глав и разделов.
* Состав иллюстраций, таблиц и листингов кода.
