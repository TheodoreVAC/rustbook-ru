# RustBook — русское издание

**Решение задач алгоритмами и структурами данных на Rust**

Полный русский перевод книги *Problem Solving with Algorithms and Data Structures
Using Rust* (оригинальное английское издание) с сохранением структуры,
иллюстраций, таблиц и всех листингов кода.

| | |
|---|---|
| Оригинал | [QMHTMY/RustBook](https://github.com/QMHTMY/RustBook) |
| Автор оригинала | Шибер (Shieber) |
| Лицензия | Apache License 2.0 |
| Язык перевода | русский |
| Объём | 10 глав, 341 страница в PDF |

---

## Что внутри

```
ru/
├── README.md            ← этот файл
├── RustBook-RU.md       ← вся книга одним Markdown-файлом (для чтения и правок)
├── glossary.md          ← единый глоссарий терминов
├── STYLE_GUIDE.md       ← правила перевода и оформления
├── chapters/            ← главы книги в Markdown (11 файлов)
├── images/              ← 69 иллюстраций, извлечённых из оригинального PDF
│   └── ru/              ← русские версии иллюстраций с переведёнными подписями
├── assets/              ← обложка издания и снимки экрана
├── code/                ← исходники примеров книги (230 файлов, как в оригинале)
├── source/              ← английский источник, извлечённый из PDF (для сверки)
└── build/               ← собранная книга
    ├── index.html       ← HTML-книга с оглавлением и навигацией
    └── rust-book-ru.pdf ← PDF-книга
```

## Быстрый старт

```bash
# открыть HTML-книгу
ru/build/index.html

# пересобрать книгу из Markdown
python tools/build_book.py --pdf
```

Подробные инструкции — в [`BUILD.md`](BUILD.md).

## Соответствие оригиналу

Русское издание построено как **полный перевод**, а не адаптация:

* переведены все 10 глав, все подразделы (177 разделов оригинального оглавления),
  вводные тексты, заключения, подписи к рисункам и таблицам, содержимое таблиц,
  библиография;
* иерархия заголовков и нумерация глав/разделов сохранены один в один;
* все **467 блоков кода** воспроизведены **побайтово идентично** оригиналу
  (проверяется автоматически, см. `tools/check_translation.py`);
* все **69 иллюстраций** и **21 таблица** перенесены без изменений;
* отрывки, разорванные вёрсткой оригинального PDF на страницах, восстановлены
  в цельные абзацы там, где это не меняло структуру, и перенесены как есть
  в остальных случаях.
