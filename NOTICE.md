# Уведомление о переводе / Translation Notice

## Русский

Каталог `ru/` и корневой файл `README.md` содержат **русский перевод** книги
**«Problem Solving with Algorithms and Data Structures Using Rust»**,
изначально опубликованной в проекте
[QMHTMY/RustBook](https://github.com/QMHTMY/RustBook).

**Русское издание является переводом и не является самостоятельным
произведением.** Авторство, название, состав и оформление оригинальной
книги принадлежат её правообладателю.

* **Автор оригинальной книги:** Шибер (Shieber).
* **Оригинальный проект:** <https://github.com/QMHTMY/RustBook>.
* **Лицензия оригинала:** Apache License 2.0 — копия приведена в файле
  [`LICENSE`](LICENSE). Русское издание распространяется на тех же условиях.
* **Проект перевода:** RustBook RU (русскоязычное сообщество Rust).

Перевод выполнен с сохранением структуры, иллюстраций, таблиц и всех
листингов кода оригинала. Полный перечень внесённых изменений — в
[`ru/TRANSLATION_NOTES.md`](../ru/TRANSLATION_NOTES.md); статус работ — в
[`TRANSLATION_PROGRESS.md`](../TRANSLATION_PROGRESS.md).

Оригинальные файлы проекта сохранены в каталоге [`original/`](original) без
каких-либо изменений.

## English

The `ru/` directory and the root `README.md` contain a **Russian translation**
of the book *«Problem Solving with Algorithms and Data Structures Using Rust»*,
originally published in the [QMHTMY/RustBook](https://github.com/QMHTMY/RustBook)
project.

**The Russian edition is a translation and is not a separate work.** Authorship,
title, content and design of the original book belong to its copyright holder.

* **Original author:** Shieber.
* **Original project:** <https://github.com/QMHTMY/RustBook>.
* **License:** Apache License 2.0 — see [`LICENSE`](LICENSE). The Russian
  edition is distributed under the same terms.
* **Translation project:** RustBook RU.

The translation preserves the structure, illustrations, tables and every code
listing of the original. The complete list of changes is in
[`ru/TRANSLATION_NOTES.md`](../ru/TRANSLATION_NOTES.md); progress is tracked in
[`TRANSLATION_PROGRESS.md`](../TRANSLATION_PROGRESS.md).

The original project files are kept unchanged in the [`original/`](original)
directory.
