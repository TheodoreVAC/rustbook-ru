# 📘 RustBook RU — о книге

---

## Что это за книга

Это практический курс по классическим **алгоритмам и структурам данных**,
написанный с использованием современного языка программирования **Rust**.
Книга разбирает фундаментальные темы информатики — от анализа сложности
до графов — и показывает, как каждая задача решается идиоматичным кодом на Rust
с полными, компилируемыми примерами.

## О чём книга — по главам

| Глава | Тема |
|:---:|---|
| 01 | **Основы Rust** — установка, синтаксис, владение и заимствование |
| 02 | **Компьютерные науки** — базовые понятия, абстракции, типы данных |
| 03 | **Анализ алгоритмов** — сложность, O-нотация, оценка производительности |
| 04 | **Структуры данных** — списки, стеки, очереди, деки |
| 05 | **Рекурсия** — принципы, деревья рекурсии, динамическое программирование |
| 06 | **Поиск** — линейный, бинарный, хеширование |
| 07 | **Сортировка** — от пузырьковой до быстрой и поразрядной |
| 08 | **Деревья** — бинарные деревья, кучи, деревья поиска |
| 09 | **Графы** — представления, обходы, кратчайшие пути |
| 10 | **Практика** — разбор задач и применение изученного |

```
RustBook-RU/

├── TRANSLATION_PROGRESS.md ← статус перевода: 10/10 глав готовы
├── original/               ← оригинальные материалы (не изменялись):
│   ├── books/              ←   PDF-издания книги
│   ├── code/               ←   исходники примеров
│   └── publication/        ←   актуальный код из печатного издания
├── ru/                     ← русское издание:
│   ├── RustBook-RU.md      ←   книга в одном Markdown-файле
│   ├── chapters/           ←   11 файлов глав

│   ├── code/               ←   230 файлов исходников
│   └── build/              ←   index.html и готовый PDF (341 стр., A5)
```

## Быстрый старт

```bash
# собрать HTML и PDF самостоятельно
pip install markdown pymupdf playwright
python -m playwright install chromium
python tools/build_book.py --pdf
```

Готовые артефакты уже лежат в [`ru/build/`](ru/build):
`index.html` — HTML-книга с оглавлением, `rust-book-ru.pdf` — сверстанная книга.
